# SmartCart AI - AI-Powered E-Commerce Platform

## Project Overview
SmartCart AI is a web-based e-commerce platform that includes a standard online store, AI product recommendations, and an AI chatbot for customer support.

## Architecture
This project uses a Client-Server architecture with the MVC (Model-View-Controller) pattern.

## Repository Structure
*   `/frontend` - User interface (HTML, CSS, JS)
*   `/backend` - Server logic, routes, and controllers
*   `/database` - ERD, SQL schema, and seed data
*   `/docs` - Software Requirements Specification (SRS) and API documentation
